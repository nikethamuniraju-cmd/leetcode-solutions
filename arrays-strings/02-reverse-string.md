## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I use two pointers, one at the beginning and one at the end of the string. I swap the characters and move the pointers toward the center until the string is reversed.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

A single-character string is an edge case because it does not need any swapping.
